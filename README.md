# Yandex Blind

Yandex Blind is a Windows 11 distribution built around the official Chromium-Gost browser.

## First build

- Chromium-Gost 156.0.8078.88 (x64), retaining its upstream ГОСТ TLS / msspi implementation.
- Yandex start page and a local new-tab page with Yandex search.
- A dedicated browser profile under `%LOCALAPPDATA%\YandexBlind\Profile`.
- A Windows installer generated by GitHub Actions.

This is **not yet a browser with a custom tab strip or custom browser chrome**. The browser window, tabs, settings and certificate UI remain Chromium-Gost's own interface. The new-tab page provides Yandex search; the default omnibox search provider can be changed to Yandex in browser settings.

## Build

GitHub Actions downloads the upstream release archive, verifies its SHA-256, packages the unchanged browser files, and builds `YandexBlind-Setup.exe` with Inno Setup. The installer is published as a workflow artifact.

Upstream release: https://github.com/deemru/Chromium-Gost/releases/tag/156.0.8078.88

## CryptoPro CSP and certificates

Chromium-Gost provides ГОСТ TLS through its upstream msspi integration. This project does not bundle, install, license, or silently modify CryptoPro CSP. CSP presence and compatibility still need validation on a real Windows 11 machine with the required CryptoPro version and certificate store.

Do not bypass certificate validation or install untrusted root certificates. Install CryptoPro only from the official vendor distribution and follow your organization's certificate policy.

## Privacy and security

- The browser uses a dedicated profile; it does not reuse an existing Chromium or Yandex Browser profile.
- Yandex is used by the startup page and local new-tab search.
- No project-specific analytics or telemetry is added.
- This does not make browsing anonymous: Yandex and visited websites receive the requests needed to provide their services. Chromium security mechanisms remain enabled.
- The upstream browser must be kept updated. This build pins an upstream release for reproducibility; update the version and checksum in the workflow when a newer verified release is selected.
